# Usage

1. Open Odoo and look for the robot icon (`🤖`) in the top navbar (Systray).
2. When an AI thread is processing background tasks (`queue_job`), a red badge counter indicates the number of active tasks for the current user.
3. Click the icon to view recent AI conversations with status indicators (Spinner for processing, Checkmark for done, Warning badge for cancel/error).
4. Click any conversation item in the dropdown menu to navigate directly to the target record's form view.
