Native AI Thread Systray Notification
=====================================

Adds a real-time top-bar Systray task tracker and notification widget to
Odoo. Allows users to track ongoing AI background jobs across all
threads and navigate back to target records in 1 click.

**Table of contents**

.. contents::
   :local:

Usage
=====

Usage
=====

1. Open Odoo and look for the robot icon (``🤖``) in the top navbar
   (Systray).
2. When an AI thread is processing background tasks (``queue_job``), a
   red badge counter indicates the number of active tasks for the
   current user.
3. Click the icon to view recent AI conversations with status indicators
   (Spinner for processing, Checkmark for done, Warning badge for
   cancel/error).
4. Click any conversation item in the dropdown menu to navigate directly
   to the target record's form view.
