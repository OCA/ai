1. Open a draft Sale Order.
2. Click **Find Products with AI**.
3. Attach requirement PDF/image and/or paste requirement text; pick AI Connection; click
   **Extract with AI** (runs in background).
4. When state is Done, edit the extracted JSON if needed, then click **Find Matches**.
5. Top 10 products are shown with Match % and Weighted %. Use **Add to Order** on any
   match to create a sale order line.
