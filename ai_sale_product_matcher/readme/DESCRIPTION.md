Find the best-matching products for a sales quotation from customer requirement
documents, images, or specification text using a vision-capable AI connection.

* Upload a customer specification PDF or image, or paste free-form requirement text.
* Extract a structured JSON object of product attributes via `ai.connection`.
* Score `product.template` records against extracted requirements using type-aware
  matching (numeric tolerance, numeric ranges, directional thresholds, and fuzzy text)
  and weighted attribute groups.
* Review the top product matches directly on the sales order and add selected matches
  as sales order lines with a single click.
