Find the best-matching products for a sales quotation from customer
requirement documents, images, or specification text using a
vision-capable AI connection.

- Upload a customer specification PDF or image, or paste free-form
  requirement text.
- Extract a structured JSON object of product attributes via
  ``ai.connection``.
- Score ``product.template`` records against extracted requirements
  using type-aware matching (numeric tolerance, numeric ranges,
  directional thresholds, and fuzzy text) and weighted attribute groups.
- Review the top product matches directly on the sales order and add
  selected matches as sales order lines with a single click.

.. IMPORTANT::
   This is an alpha version, the data model and design can change at any time without warning.
   Only for development or testing purpose, do not use in production.
   `More details on development status <https://odoo-community.org/page/development-status>`_

Use Cases / Context
===================

Sales teams frequently receive customer specifications as PDFs, images,
or unstructured emails. Manually comparing those requirements against a
large product catalog with many technical attributes is time-consuming.
This module automates requirement extraction and product scoring while
keeping a human in the loop via editable JSON requirements and
transparent match breakdowns.

Configuration
=============

1. Configure a vision-capable ``ai.connection`` record under **AI >
   Configuration > Connections**.
2. Set the default **AI Connection** under **Sales > Configuration >
   Settings > AI Sale Product Matcher**, or select an AI connection
   directly on the sales order or in the requirement wizard.

Usage
=====

1. Open a Sales Order and click **Find Products with AI**.
2. Attach a requirement PDF/image and/or paste requirement text, then
   click **Extract with AI**.
3. Review or edit the extracted JSON requirements, optionally select a
   product category filter, and click **Find Matches**.
4. Review the ranked matches and click **Add to Order** on any match to
   create a sales order line.
