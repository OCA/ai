In *Message Import > Configuration > Settings*:

- *Create vendors* and its minimum confidence: whether a vendor that does not
  exist is created from the document.
- *Create products (purchases)* and its minimum confidence: whether a product
  that does not exist is created from a complete line.

In *Message Import > Configuration > AI prompts*, write the prompt *Document
type: vendor quote (purchase)*, which tells the AI when a document is a vendor
quote and who its vendor is.
