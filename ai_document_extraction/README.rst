This module extracts structured invoice data (partner, invoice number,
payment reference, date, currency, lines and amounts) from uploaded PDF
or image documents by rendering all document pages and sending them
through a configured ``ai.connection``.

The extracted data is applied to draft customer invoices and vendor
bills (``account.move``) either automatically when importing/uploading
an attachment on a journal with an AI connection configured, or on
demand via the **Extract with AI** button. If the partner name cannot be
matched automatically, a review wizard lets the user select or create
the partner.

.. IMPORTANT::
   This is an alpha version, the data model and design can change at any time without warning.
   Only for development or testing purpose, do not use in production.
   `More details on development status <https://odoo-community.org/page/development-status>`_

Use Cases / Context
===================

Accounting teams receive invoices in many formats. Reading them manually
is slow and error prone. This module automates the initial data-entry
step while keeping a human in the loop: the extraction is applied to a
draft move that a user reviews and posts. All AI components run
on-premises (Ollama), so document data never leaves the local
infrastructure when a local endpoint is used.

Configuration
=============

1. Create or configure an *AI Connection* under *Settings > Technical >
   AI > AI Connections* using your preferred vision-capable AI
   connection provider.
2. Link the AI connection either:

   - Per journal: in *Accounting > Configuration > Journals*, open a
     purchase or sales journal and set **AI Document Extraction
     Connection** under the *Advanced Settings* tab.
   - Company-wide: in *Accounting > Configuration > Settings*, under the
     **AI Document Extraction** section, select the default **AI
     Connection** and adjust the **Partner Match Threshold** (default:
     ``85``).

Usage
=====

1. Go to *Accounting > Vendors > Bills* (or *Customers > Invoices*).
2. Upload a single-page or multi-page PDF or image invoice, or attach it
   to a draft invoice and click **Extract with AI**.
3. When extraction finishes, *AI Extraction State* becomes **Done** and
   the partner, invoice date, reference, currency, and invoice lines are
   populated.
4. If the partner could not be matched automatically, click **Review
   Extraction** to select the partner and apply it to the draft move.
