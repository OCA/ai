Adds a reviewed OpenWebUI description-drafting action to Odoo project
tasks. A proposed description is shown in an editable wizard and only
written after the user explicitly applies it.

.. IMPORTANT::
   This is an alpha version, the data model and design can change at any time without warning.
   Only for development or testing purpose, do not use in production.
   `More details on development status <https://odoo-community.org/page/development-status>`_

Configuration
=============

Install ``ai_oca_bridge_openwebui``,
``ai_oca_bridge_openwebui_discuss``, and this addon. Create one active
bridge with **Usage: Project Task Description**, **Result Kind:
Immediate**, **Result Type: No processing**, and a valid OpenWebUI
model/token. Restrict its groups/domain as appropriate. The caller must
have read access to the task; applying the draft requires write access.

Usage
=====

The request includes the task title, existing description, project,
deadline, assignees and tags. The model is instructed not to invent
facts. Its response is converted from plain text to safe HTML and
presented for review; it does not overwrite the task automatically.
