AI OCA MCP OAuth

This module lets MCP clients such as Claude connect to an ai_oca_mcp server through an OAuth sign-in, instead of a key entered by hand.

When the user clicks Connect (or Authenticate) in the client, a browser opens on Odoo. The user signs in, reviews the server, its tools and where the client will return to, and clicks Allow. The client then receives a key and uses it like any key created with Add Key.

Only internal users of the Connect AI Clients with OAuth group can allow the access. The key belongs to the user who allowed it, so the tools run with that user’s access rights. It appears in the server’s keys and can be expired there to disconnect the client, and the user can disconnect it in their preferences. It also stops working when the user is archived or removed from the group, and expires when OAuth is turned off on the server or this module is uninstalled.

The module implements the parts of the MCP authorization specification that Claude needs: the authorization code flow with PKCE (S256), protected resource and authorization server metadata, and dynamic client registration.

Configuration

  • Open the MCP server in AI > MCP Server and check OAuth.
  • Add the users who may connect AI clients to the group Connect AI Clients with OAuth (Settings > Users & Companies > Groups, in developer mode).
  • Make sure the web.base.url system parameter is the URL clients use to reach Odoo (set web.base.url.freeze to True behind a reverse proxy). The server’s URL must match the URL entered in the client exactly.

Optional system parameters:

  • ai_oca_mcp_oauth.redirect_uris: the redirect URIs clients may use, separated by spaces or new lines. For localhost and 127.0.0.1 the port is ignored. By default, Claude and Claude Code are allowed: https://claude.ai/api/mcp/auth_callback http://localhost/callback http://127.0.0.1/callback
  • ai_oca_mcp_oauth.token_lifetime_days: how many days an issued key is valid (default 30). When it expires, the client asks the user to connect again.

Usage

Claude (web, Desktop)

  • Go to Customize > Connectors, click Add custom connector and enter the server’s URL.
  • Click Connect. Odoo opens: sign in if needed, then click Allow.

Claude Code

  • Run claude mcp add --transport http odoo <URL>.
  • Run /mcp, select the server and choose Authenticate. Odoo opens in the browser: sign in if needed, then click Allow.

Disconnecting a client

  • Open your preferences, tab Account Security: the clients you connected are listed under AI Clients. Click Disconnect on the one to remove.

Known issues / Roadmap

  • Refresh tokens are not issued. When a key expires, the user connects again.
  • Client registrations are not stored: the redirect URI allow-list, PKCE and the user’s approval protect the flow.
  • Client ID Metadata Documents are not supported. Claude falls back to dynamic client registration.
  • When auth_oauth_server (OCA/server-auth#1032) is available, this module could rely on it for the authorization server and keep only the link with the MCP servers.
