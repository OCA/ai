## Claude (web, Desktop)

- Go to `Customize > Connectors`, click **Add custom connector** and enter the
  server's **URL**.
- Click **Connect**. Odoo opens: sign in if needed, then click **Allow**.

## Claude Code

- Run `claude mcp add --transport http odoo <URL>`.
- Run `/mcp`, select the server and choose **Authenticate**. Odoo opens in the
  browser: sign in if needed, then click **Allow**.

## Disconnecting a client

- Open your preferences, tab **Account Security**: the clients you connected are
  listed under **AI Clients**. Click **Disconnect** on the one to remove.
