This module replaces the integration of AI from Odoo to ChatGPT through
Odoo by a server that offers an OpenAI compatible API, like vLLM,
llama.cpp, LiteLLM or OpenAI itself.

Use Cases / Context
===================

Without this module, Odoo is providing an AI solution that sends the
data to Odoo and Odoo to ChatGPT. There are strong concerns on this
topic about Data Protection.

For this reason, we defined a module that allows to integrate with any
server that offers an OpenAI compatible API, like a self-hosted LLM.

Configuration
=============

To configure this module, you need to create 2 parameters:

- *ai_oca_native_generate_openai.url*: Base URL of the API, like
  ``https://llm.example.com/v1``
- *ai_oca_native_generate_openai.model*: Model to use

Optionally, you can also set:

- *ai_oca_native_generate_openai.api_key*: API key, if the server
  requires one
- *ai_oca_native_generate_openai.temperature*: Temperature of the model
- *ai_oca_native_generate_openai.timeout*: Timeout of the request in
  seconds (60 by default)

If the URL or the model are not set, the standard Odoo IAP service is
used.
