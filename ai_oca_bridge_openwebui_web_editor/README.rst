Routes Odoo 18 HTML editor AI text generation and translation requests
to an OpenWebUI model selected through an OCA AI Bridge, while keeping
the standard editor dialog and response contract.

Configuration
=============

Install ``ai_oca_bridge_openwebui`` and this addon. Create exactly one
active OpenWebUI bridge with **Usage: HTML Editor**, **Result Kind:
Immediate**, **Result Type: No processing**, a model identifier, URL and
token. Optional bridge groups restrict access. Do not put the API token
in frontend assets.

Usage
=====

The addon overrides the existing ``/html_editor/generate_text``
controller route. It forwards the prompt and conversation history
server-side to OpenWebUI and returns plain text to Odoo. It fails closed
when the integration is installed but no editor bridge is configured; it
does not fall back to Odoo IAP. Only HTML-editor text assistance is
rerouted.
