This addon connects Odoo Discuss and eligible chatter records to
OpenWebUI through the OCA AI Bridge. It packages the message hook,
bounded history/context, attachment handling, and OpenWebUI agentic
execution separately from the shared provider configuration.

.. IMPORTANT::
   This is an alpha version, the data model and design can change at any time without warning.
   Only for development or testing purpose, do not use in production.
   `More details on development status <https://odoo-community.org/page/development-status>`_

Configuration
=============

Install ``ai_oca_bridge_openwebui``, ``ai_oca_bridge_chatter``, and this
addon. Create an OpenWebUI bridge with **Usage: Chatter**, **Result
Kind: Immediate**, and **Result Type: Post a Message**. Configure its
model, URL, token, and optional tools. Assign the bridge to an internal
Odoo AI user and add that user to the relevant Discuss conversations.
The optional Odoo Model field can restrict eligible chatter records.

Usage
=====

Odoo supplies the current chatter message, bounded prior history,
selected record context, and eligible attachments. OpenWebUI executes
the configured model and tools. The final assistant response is posted
to the originating chatter by the configured internal AI user. This
addon owns chatter behavior; the base provider addon owns
connection/model configuration.
