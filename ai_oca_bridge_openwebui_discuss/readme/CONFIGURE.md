Install `ai_oca_bridge_openwebui`, `ai_oca_bridge_chatter`, and this addon. Create an OpenWebUI bridge with **Usage: Chatter**, **Result Kind: Immediate**, and **Result Type: Post a Message**. Configure its model, URL, token, and optional tools. Assign the bridge to an internal Odoo AI user and add that user to the relevant Discuss conversations. The optional Odoo Model field can restrict eligible chatter records.
