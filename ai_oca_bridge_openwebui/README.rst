This module provides the shared OpenWebUI provider layer for OCA AI
Bridge: server-side credentials, model/tool catalog synchronization, and
a reusable non-streaming chat-completion helper.

Use a separate integration addon for each Odoo use case:

- ``ai_oca_bridge_openwebui_discuss`` for Discuss and chatter;
- ``ai_oca_bridge_openwebui_task`` for project-task description
  drafting;
- ``ai_oca_bridge_openwebui_web_editor`` for the HTML editor's AI text
  tools.

OpenWebUI remains responsible for model execution and provider-specific
behavior. This base addon does not send business records to an LLM by
itself.

   This is an alpha version, the data model and design can change at any time without warning.
   Only for development or testing purpose, do not use in production.

Configuration
=============

Odoo
----

1. Install ``ai_oca_bridge_openwebui``.
2. Create an AI Bridge with payload type **OpenWebUI Chat**.
3. Configure the OpenWebUI chat-completions URL, token authentication,
   and model identifier. Model/tool catalog synchronization is optional;
   manual model IDs are supported.
4. Install one or more use-case addons and select the corresponding
   **Usage** on its bridge:

   - **Chatter** for ``ai_oca_bridge_openwebui_discuss``;
   - **Project Task Description** for ``ai_oca_bridge_openwebui_task``;
   - **HTML Editor** for ``ai_oca_bridge_openwebui_web_editor``.

5. Keep the API token server-side and restrict bridge records to
   authorized groups.

The provider addon only stores shared connection/configuration and
exposes server-side request helpers. It does not run an LLM call until
an integration addon invokes it.

Usage
=====

Responsibilities
----------------

Odoo stores bridge configuration, checks the invoking user's
permissions, and supplies only the context needed by the selected
integration. OpenWebUI handles the configured model, knowledge bases,
tools, and provider-specific behavior.

Integration behavior
--------------------

- Discuss/chatter requests are handled by
  ``ai_oca_bridge_openwebui_discuss`` and posted back as the configured
  AI user.
- Project task descriptions are drafted through a review wizard by
  ``ai_oca_bridge_openwebui_task``; the task is not updated until a user
  applies the draft.
- HTML editor requests are handled by
  ``ai_oca_bridge_openwebui_web_editor``; it returns the plain-text
  response expected by Odoo's editor.

Each integration has its own bridge usage and context policy. The
OpenWebUI API token is used only by server-side Odoo code and is never
sent to the browser.
