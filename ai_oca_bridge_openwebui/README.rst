AI OCA Bridge OpenWebUI
========================

This module connects Odoo Discuss with OpenWebUI through its
OpenAI-compatible API.

Odoo remains responsible for users, access rights, Discuss channels and
conversation history. OpenWebUI remains responsible for models, prompts,
knowledge bases, agents and external tools.

Configuration

See ``readme/CONFIGURE.md`` for installation and configuration steps.
See ``readme/USAGE.md`` for the request format and responsibilities.
