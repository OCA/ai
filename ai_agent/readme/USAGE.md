- In Discuss, click an agent of the *Agents* category and write your first
  message: the conversation is created and the agent answers it.
- From any screen, open the robot menu of the top bar and click an agent:
  the new conversation is about the view you are looking at (e.g. the
  filtered list of sale orders, or the order of a form view).
- On any record with a chatter, mention the agent to ask it about that
  record in the chatter, visible to your colleagues.
